# Test Plan: Agent Skills and Workshop

## Scope

This plan covers the skill pipeline suites in `src/skills/`: discovery and filtering, loading and precedence, the runtime snapshot and dispatch, the personal and team library, the install and update lifecycle, the literal-secret scanner, the Workshop change feed and review loop, and the operator command surfaces in `src/cli/`. The shipped skill content is covered by the repository-content suite that scans every bundled `SKILL.md`. The agent tool surface (`skill_workshop`) and the node-host MCP bridge that exposes it are owned by the agent runtime and are out of scope here.

## Test Infrastructure

- The discovery, loading, and library suites build real temporary skill trees on disk with real `SKILL.md` files, so the frontmatter contract, the path containment rules, and the file identity of the usage counters are proven against the filesystem.
- The library, change feed, and upload suites run against temporary SQLite state databases created by the shared OpenClaw state database helpers, so the revision and cursor semantics are proven against the real persistence layer.
- The command suites stub the Gateway transport and assert on the emitted output and the exit code, so no Gateway process is required.
- The repository-content suite scans the shipped `skills/` directory in place, so a credential added to a bundled skill fails the build.
- The workshop suites use a temporary Workshop root and a real session manager, so the versioning, the archive, the restore, and the undo paths are proven end to end against the files the assistant actually wrote.
