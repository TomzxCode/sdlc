## Sync drift: 2026-10-19

- Stale Data Model: the Agent table names the lifecycle field `status`, but the field is `state`. `packages/core/src/types/agents/agents.ts:616` declares `state: AgentState`, and `packages/core/src/types/agents/agent-state.ts:7` defines `AGENT_STATES = ["idle", "active", "running", "paused", "error"]`. The spec's enum `idle/active/error/paused` omits `running`.
- Stale Data Model: the Agent table marks `permissionPolicy` as `not null`, but it is optional. `packages/core/src/types/agents/agents.ts:642` declares `permissionPolicy?: AgentPermissionPolicy`, and `packages/core/src/agents/agent-permission-policy.ts:188-205` resolves an agent with no policy from the project default and then from the unrestricted built-in default.
- Stale Data Model: the Agent table types `pauseReason` as an enum, but it is a free-form string. `packages/core/src/types/agents/agents.ts:638` declares `pauseReason?: string`. The engine writes `error-retry-exhausted`, `error-unrecoverable`, and `heartbeat-model-unavailable` (`packages/engine/src/agents/agent-heartbeat-error-recovery.ts:14-16`), and the operator surfaces write other values.
- Missing Data Model: the Agent table omits the fields the code reads. `packages/core/src/types/agents/agents.ts:609-614` carries `roles` and the deprecated `role` projection, `:626` carries `metadata`, `:636` carries `runtimeConfig`, `:640` carries `permissions`, `:648` carries `lastError`, `:644-647` carry the token totals, and `:670` carries `heartbeatProcedurePath`.
- Stale API Contract: `POST /api/agents` does not accept a `model` field. The accepted body fields are destructured at `packages/dashboard/src/routes/register-agent-core-routes.ts:227-244`: `name`, `role`, `roles`, `metadata`, `title`, `icon`, `reportsTo`, `runtimeConfig`, `permissions`, `permissionPolicy`, `instructionsPath`, `instructionsText`, `soul`, `memory`, `bundleConfig`, `heartbeatProcedurePath`.
- Stale API Contract: the documented response is `200 OK` with an `agent` field, but the route returns `201` with a bare agent object. `packages/dashboard/src/routes/register-agent-core-routes.ts:373` calls `res.status(201).json(agent)`. The only `{ agent }` response form in this file is the `GET /api/agents/:id` response at `packages/dashboard/src/routes/register-agent-core-routes.ts:488`.
- Missing API Contract: the API Contracts section documents one route, but the agent surface is much wider and includes the permission editing route that FR-6 depends on. `packages/dashboard/src/routes/register-agent-runtime-routes.ts:91` registers `PATCH /api/agents/:id/permissions`, and `packages/dashboard/src/routes/register-agent-core-routes.ts:191,498,662,907` register list, detail, update, and delete.
- Stale Sequence: the Execution sequence names the sandbox backends as "bubblewrap/spawn", and no spawn backend exists. The backend set is native, sandbox-exec, bubblewrap, docker, podman, and custom (`packages/engine/src/sandbox/types.ts:53`, `packages/engine/src/sandbox/index.ts:44-59`, `docs/settings-reference.md:603`). The sequence also omits the resolution precedence (per-task PROMPT override, then project setting, then native default) implemented in `packages/core/src/sandbox/sandbox-prompt-override.ts:33-43` and applied to task sessions in `packages/engine/src/executor/run-implementation.ts:2148-2151`.
- Stale Sequence: the Durable recovery sequence names two park reasons, but the code has a third. `packages/engine/src/agents/agent-heartbeat-error-recovery.ts:16` defines `HEARTBEAT_MODEL_UNAVAILABLE_PAUSE_REASON`, and `packages/engine/src/agents/agent-heartbeat-error-recovery.ts:107-112` admits that park to the retry budget through a path that is independent of the `lastError` classification.
- Stale Technical Decision: the "Sandbox pluggable" row names "bubblewrap / spawn-based" as the backends. `packages/engine/src/sandbox/index.ts:35-60` resolves native, bubblewrap, container, sandbox-exec, or a test override, and `packages/engine/src/sandbox/container.ts` and `packages/engine/src/sandbox/sandbox-exec-backend.ts` implement the two backends the spec omits.
- Missing Technical Decision: no row records that sandbox settings are inert unless the experimental flag is on. `packages/core/src/sandbox/sandbox-settings.ts:4-6` gates the feature, and `packages/engine/src/executor/configured-command.ts:29-31` resolves the configured-command backend through that path.
- Stale Architecture: the diagram places "agent heartbeat (durable agents)" as a consumer of the task store, but the recovery budget is shared by two entry paths and is enforced in one helper. `packages/engine/src/agents/agent-heartbeat-error-recovery.ts:12-16` defines the single budget key and the shared limit, `packages/engine/src/agent-heartbeat.ts:2426` and `packages/engine/src/self-healing.ts:16197` are the two emitters of the same `agent:auto-recover-error-state` event, and `packages/engine/src/agents/agent-heartbeat-error-recovery.ts:40-61` reads the legacy and current attempt counters as one budget. The Technical Decisions table already states the shared budget, so the diagram and the table disagree.
